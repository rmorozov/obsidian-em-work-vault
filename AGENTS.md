# Repository guidance

This public repository is a reproducible, synthetic Obsidian engineering-management vault. Never commit real work notes, correspondence, personnel assessments, credentials, tokens, or private-vault content.

Inspect the actual LifeOS configuration and upstream template syntax before changing plugin-dependent templates. LifeOS has plugin ID `periodic-para`. Keep PARA and periodic notes; use Obsidian for management interpretation and links, not as a second Azure DevOps tracker.

Keep generated daily/weekly notes separate from templates. Make changes on a branch, validate helper scripts with synthetic fixtures, and describe Obsidian interactions that cannot be verified headlessly.
